# 🇯🇵 일본 여행 스케줄 플래너

도시를 선택하면 입국부터 출국까지 시간별 관광지·맛집 일정을 자동으로 생성해주는 웹 애플리케이션입니다.

## 주요 기능

- **도시 선택 & 경로 설정**: 후쿠오카, 나가사키, 오사카, 도쿄, 교토, 벳푸, 구마모토, 유후인 등 인기 도시 지원
- **자동 일정 생성**: 입국 → 관광 → 식사 → 이동 → 출국까지 시간별 최적 스케줄
- **맛집 추천**: 도시별 필수 맛집과 추천 메뉴 포함
- **교통편 안내**: 도시 간 신칸센/특급열차 정보, 항공편 시간표
- **유연한 옵션**: 1박2일 ~ 4박5일, 출발 시간 선택 가능
- **인쇄 기능**: 일정표 인쇄 지원

## 지원 도시

| 도시 | 특징 |
|------|------|
| 🍜 후쿠오카 | 규슈의 관문, 라멘과 야타이의 성지 |
| ⛪ 나가사키 | 이국적인 분위기와 역사가 공존하는 항구 도시 |
| 🏯 오사카 | 맛의 도시, 쿠이다오레 문화의 본고장 |
| 🗼 도쿄 | 전통과 현대가 조화로운 메가시티 |
| ⛩️ 교토 | 천년 고도, 일본 전통문화의 중심지 |
| ♨️ 벳푸 | 일본 최대의 온천 도시 |
| 🐻 구마모토 | 구마몬의 고장, 웅장한 성의 도시 |
| 🌿 유후인 | 그림 같은 온천 마을 |

## 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 `http://localhost:5000` 접속

## 기술 스택

- **백엔드**: Python / Flask
- **프론트엔드**: HTML / Tailwind CSS / Vanilla JS
- **데이터**: JSON 기반 도시·맛집·교통 정보
